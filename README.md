# Lightning-Scroller
Tired of slow scrolling websites like Facebook?  We have the answer.

Installation (takes ~30 seconds)

Download and unzip the file above somewhere permanent (e.g. ~/fb-scroller/)
Open Chrome → go to chrome://extensions
Toggle Developer mode ON (top-right)
Click Load unpacked → select the fb-scroller folder
The ⚡ icon appears in your toolbar


How to use

Go to facebook.com (home feed, groups, marketplace — any feed page)
Click the ⚡ toolbar icon
Hit ▶ Start — it immediately begins blasting down the feed

The green HUD overlay on the page shows live progress. The popup tracks:

Posts captured (deduplicated)
RAM buffer (fills up to 200 MB)
Disk batches (IndexedDB flushes when RAM fills)
